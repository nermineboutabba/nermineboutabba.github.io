Live Website: **https://nermineboutabba.github.io**  
GitHub Profile: **https://github.com/nermineboutabba**

## Features
- **Luminous Bento & Glassmorphism 2.0 (Light Mode)** with multi-tone aurora mesh gradients and 3D tilt micro-interactions.
- **Bilingual (English / French)** instant switcher translating UI copy, project dossiers, experience timelines, and linking to localized 2026 ATS CVs and Application Dossiers.
- **Recruiter Tech-Stack Matcher**: Domain filter tabs + stack pills + Top 9 Flagships / All 18 Systems toggle.
- **Slide-Over Engineering Dossier Drawer**: Curated UI screenshots & UML carousels (with strict NDA code-redaction safeguards) + animated SVG architecture flows.
- **Interactive Pipeline Inspector** & **CLI Command Palette (`Ctrl+K`)**.
- **2026 Executive Recruiter Kit & QR Code Hub**: Scannable QR codes + direct downloads for `CV-EN.pdf`, `CV-FR.pdf`, `APPLICATION-DOSSIER-EN.pdf`, `DOSSIER-DE-CANDIDATURE-FR.pdf`, research paper, and verified certificates.

## Deployment to GitHub Pages
1. Create a public GitHub repository named `nermineboutabba.github.io` under `https://github.com/nermineboutabba`.
2. Push the contents of `D:\work\Portfolio` to the `main` branch.
3. GitHub Pages will automatically serve `index.html` at `https://nermineboutabba.github.io/`.
